# Contributing to NeuroCortex SRDF

Thank you for your interest in contributing.

## Project status

This is a research project. The R4 phase (S04) is **frozen** and
must not be modified. Contributions that touch frozen phases will
be declined.

## How to contribute

### Reporting issues

Open an issue with:

- Clear description.
- Steps to reproduce.
- Expected vs. actual behavior.

### Submitting changes

1. Fork the repository.
2. Create a branch (`feature/your-feature`).
3. Make changes following the naming conventions.
4. Add tests if applicable.
5. Submit a pull request.

### Naming conventions

- Files: `srdf_<phase>_<type>.<ext>`
  (e.g. `srdf_s01_foundational_prototype.ipynb`).
- Commits: `<phase>: <short description>`
  (e.g. `S01: finalize structure`).

## Frozen phases

- **S04 / R4** — Frozen. Do not modify.
- **S01, S03** — Closed. Modifications require explicit reasoning.

## Code of Conduct

By participating, you agree to abide by the `CODE_OF_CONDUCT.md`.
