# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.4.x   | :white_check_mark: |
| 0.3.x   | :white_check_mark: |
| 0.1.x   | :warning: (historical) |

## Reporting a Vulnerability

This is a research framework. If you discover a security issue:

1. **Do not** open a public issue.
2. Contact the maintainer directly:
   - Email: mohammedqaid.amanlift@gmail.com
3. Include:
   - Description of the issue
   - Steps to reproduce
   - Potential impact

You will receive a response within 7 days.

## Scope

This policy applies to the code and data in this repository.
It does not cover external datasets (e.g., OpenML) or third-party
dependencies.
