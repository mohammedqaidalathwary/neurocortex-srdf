# S04 — OpenML Generalization (R4)

**Phase identifier**: S04  
**Phase name**: OpenML Generalization  
**Framework**: NeuroCortex — Self-Reinforcing Development Framework (SRDF)  
**Role within the framework**: Large-scale, protocol-controlled validation  
**Status**: Structure defined

**Framework context**: S04 is the final phase of the multi-phase
experimental framework. It provides large-scale, protocol-controlled
validation of the SRDF workflow established in the earlier phases.
See the repository root `README.md` for the full phase list.

---

## 1. Purpose

S04 (internally designated R4) provides a large-scale,
protocol-controlled validation of the SRDF workflow. Unlike the
earlier phases, S04 is designed to operate under:

- a pre-registered protocol,
- a frozen execution contract,
- a cohort locked before execution,
- an explicit source lock,
- recorded raw case-level evidence.

## 4. Boundary of claims

S04 is designed as a controlled empirical validation. Its claims
will be bounded by the frozen protocol once it is placed. No
empirical claim will be made before execution.
